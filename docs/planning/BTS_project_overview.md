# 베이스볼 팀 시스템(BTS) 프로젝트 기획서

## 1. 프로젝트 개요

- **앱 이름**: 베이스볼 팀 시스템 (BTS)
- **프로젝트 주제**: 사회인 야구단 운영을 위한 매니저 앱
- **팀명**: 마개사
- **한 줄 소개**: 마구마구 개발하는 사람들

### 프로젝트 목적
사회인 야구단 운영 시 자주 발생하는 문제인 **경기 일정 관리**, **참석 여부 파악**, **라인업 확정**, **선수 정보 및 기록 관리**를 하나의 앱에서 효율적으로 처리할 수 있도록 지원한다.  
특히 감독이 경기마다 참석 가능한 선수를 빠르게 파악하고, 선수 배치를 보다 쉽게 결정할 수 있도록 하며, 기록원은 CSV 파일 업로드 방식으로 간편하게 반영할 수 있도록 한다.

---

## 2. 문제 정의

사회인 야구단 운영에서는 다음과 같은 불편함이 반복적으로 발생한다.

- 경기 일정이 여러 채널로 공유되어 관리가 어렵다.
- 어떤 선수가 특정 경기 일정에 참석 가능한지 한눈에 보기 어렵다.
- 감독이 참석 가능 선수와 포지션을 종합해 라인업을 구성하는 데 시간이 많이 든다.
- 선수 기록이 분산되어 있어 시즌 단위 관리가 어렵다.
- 기록원이 입력한 경기 기록을 체계적으로 저장하고 조회하기 어렵다.

### 해결 방향
본 프로젝트는 위 문제를 해결하기 위해 다음을 핵심 가치로 삼는다.

1. **경기 운영 정보의 일원화**  
   경기 일정, 참석 여부, 라인업, 경기 기록을 하나의 앱에서 관리한다.

2. **감독 의사결정 지원**  
   참석 현황과 선수 정보를 기반으로 라인업 추천 기능을 제공한다.

3. **기록 관리의 효율화**  
   기록원은 CSV 업로드만으로 경기 기록을 저장할 수 있도록 하여 입력 부담을 줄인다.

## 5. MVP 정의

### MVP 목표
사회인 야구단 운영에 꼭 필요한 기능만 우선 구현하여, 실제 경기 준비와 운영에 바로 사용할 수 있는 수준의 앱을 만든다.

### MVP 포함 기능
- 감독/선수 역할 구분
- 경기 일정 등록 및 조회
- 선수의 참석 여부 제출
- 감독의 참석 현황 확인
- 라인업 확정 및 조회
- 선수 정보 등록 및 조회
- 경기 기록 저장 및 조회
- 기록원의 CSV 파일 업로드
- AI 라인업 추천 및 추천 이유 설명

### MVP 제외 기능
- 푸시 알림
- 고급 통계 대시보드
- 외부 서비스 연동
- 영상/이미지 기반 자동 분석
- 커뮤니티형 소통 기능

## 7. AI 라인업 추천 기능

### 기능 목적
감독이 참석 가능한 선수, 선수별 포지션, 기존 기록 등을 고려하여 경기 라인업을 보다 빠르고 합리적으로 구성할 수 있도록 지원한다.

### 입력 정보 예시
- 참석 가능 선수 목록
- 선수 주 포지션 / 가능 포지션
- 시즌 누적 기록
- 최근 출전 이력

### 출력 정보 예시
- 추천 선발 라인업
- 포지션별 배치 결과
- 추천 이유 설명
  - 예: 해당 선수는 최근 출석률이 높고 주 포지션 적합도가 높음
  - 예: 해당 선수는 최근 타격 지표가 우수하여 중심 타선 배치 추천

### 유의 사항
AI 추천은 **감독의 의사결정을 보조하는 기능**이며, 최종 라인업 확정 권한은 감독에게 있다.

## 9. CSV 업로드 정책

기록원은 직접 앱에서 세부 기록을 하나씩 입력하는 대신, **CSV 파일 업로드 방식**으로 경기 기록을 등록한다.

### 기대 효과
- 기록 입력 시간 단축
- 기존 기록 양식과의 호환성 확보
- 대량 데이터 반영 용이

### 기본 흐름
1. 기록원이 경기 종료 후 CSV 파일 준비
2. 앱에서 해당 경기 선택
3. CSV 파일 업로드
4. 시스템이 경기 기록으로 저장
5. 감독/선수가 기록 조회 가능

### 향후 보완 가능 항목
- CSV 형식 검증
- 업로드 실패 사유 안내
- 중복 업로드 방지

---

## 10. 기대 효과

- 감독은 경기 준비 시간을 줄이고 라인업 결정을 더 효율적으로 진행할 수 있다.
- 선수는 경기 일정과 본인 출전 여부를 쉽게 확인할 수 있다.
- 기록원은 기록 업로드 작업을 간편하게 처리할 수 있다.
- 팀 전체적으로 경기 운영 정보와 선수 기록이 체계적으로 축적된다.

## 11. 차별점

본 프로젝트는 단순한 일정 관리 앱이 아니라, 다음 요소를 함께 제공하는 데 의미가 있다.

- **참석 여부 기반 운영 관리**
- **라인업 확정 프로세스 지원**
- **기록원 CSV 업로드 기반 기록 반영**
- **AI 추천을 통한 감독 의사결정 보조**

즉, 사회인 야구단 운영에 필요한 핵심 흐름을 하나의 서비스 안에서 연결하는 것이 본 프로젝트의 강점이다.

- 경기 기록 시각화 대시보드

- 알림 기능 추가
